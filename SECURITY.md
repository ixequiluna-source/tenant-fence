# Security and responsible use

These are synthetic local experiments. Do not submit credentials, personal data or customer payloads in issues, reports or screenshots. Use the contact address published at https://ixequiluna.ai for private vulnerability reports; send a minimal synthetic reproduction first.

Version 0.1.x is an initial public release. There is no security-certification claim, disclosure bounty or guaranteed response-time commitment. Do not expose demonstration servers to a network or use demo credentials in another environment.

Reports intentionally omit raw payloads. Review generated artifacts before publishing them. Input files and operating-system metadata remain your responsibility.
